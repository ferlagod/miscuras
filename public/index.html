Mis Curas: Política de privacidad

Última actualización: 7 de junio de 2026

La aplicación "Mis Curas" es una herramienta de apoyo a la toma de decisiones dirigida exclusivamente a profesionales de enfermería. El diseño de este software prioriza de forma absoluta la privacidad, procesando la información de evaluación localmente y limitando las comunicaciones externas a funciones técnicas específicas debidamente declaradas.

1. Recopilación y almacenamiento de datos

  • Datos locales: La aplicación funciona mediante una base de datos local que se inicializa de forma autónoma con archivos predefinidos. No requiere conexión a servidores externos para realizar las consultas clínicas o consultar el catálogo de productos.
  • Preferencias: Los ajustes de la interfaz, como el idioma y el tema visual, se guardan exclusivamente en el almacenamiento local del dispositivo mediante mecanismos nativos del sistema operativo.
  • Uso de la cámara (Regla Virtual): La aplicación solicita el permiso de cámara exclusivamente para la función de medición de heridas en tiempo real mediante realidad aumentada. El flujo de vídeo se procesa de forma efímera en la memoria volátil del dispositivo para calcular distancias físicas. No se realiza ninguna captura fotográfica o de vídeo, no se almacena en el dispositivo y no se transmite ninguna imagen a servidores externos, garantizando una privacidad clínica total.
  • Formulario de sugerencias: La aplicación incluye un formulario opcional para proponer la adición de nuevos productos. La información introducida se transmite a través del proveedor de servicios externo Formspree, encargado de procesar la petición y redirigirla a proyectos@oniros.eu. Formspree puede recopilar metadatos técnicos (como la dirección IP) estrictamente por motivos de seguridad y prevención de spam. El uso de esta función está sujeto a la política de privacidad de Formspree.
  • Asistente Educativo IA: La aplicación incorpora una función opcional de asistencia teórica interactiva que se conecta con la API de Google Gemini. Al solicitar una aclaración, el sistema envía únicamente datos técnicos genéricos y despersonalizados extraídos de la base de datos local (fase del lecho de la herida, estado del exudado y directriz teórica de curas). Bajo ninguna circunstancia se capturan, transmiten o almacenan nombres, datos de salud, historias clínicas ni imágenes reales de pacientes. La consulta viaja de forma cifrada y segura hacia los servicios de Google AI.
  • Privacidad del paciente: El código de la aplicación ha sido diseñado para no recopilar información personal ni datos identificativos de pacientes. Las selecciones de evaluación de heridas se mantienen únicamente en la memoria temporal durante el uso de la pantalla correspondiente y se destruyen al cerrarla.

2. Permisos, Telemetría y servicios de terceros

  • Permiso de Cámara: Utilizado de forma restrictiva, aislado de la red y sin acceso a la memoria de almacenamiento. Solo se activa a petición del usuario para cálculos matemáticos locales.
  • Carencia de rastreadores: No se integra ningún tipo de SDK de terceros para publicidad, rastreo de uso (trackers), herramientas de analítica comercial o recolección automatizada de errores. La privacidad es total y el código es auditable.
  • Uso de red: El permiso de acceso a Internet del dispositivo se utiliza de forma restrictiva y exclusiva para:
    • Renderizar determinados recursos gráficos de la interfaz.
    • La transmisión unidireccional del formulario de sugerencias (Formspree).
    • La comunicación directa y cifrada con la API de Google Gemini para la generación de las explicaciones de texto del Asistente Educativo.

3. Eliminación de datos

La eliminación total de los datos de configuración locales o contadores de la aplicación se efectúa de forma inmediata e irreversible al ejecutar cualquiera de las siguientes acciones en el dispositivo:

  • Desinstalar la aplicación del sistema.
  • Borrar la caché y los datos de la aplicación directamente desde los ajustes del sistema operativo Android.

4. Responsabilidad clínica y limitaciones de la IA

La aplicación es un recurso puramente consultivo e informativo basado en las directrices de la GNEAUPP y el marco teórico TIME.

Las sugerencias automatizadas de la base de datos y las explicaciones redactadas por el Asistente Educativo IA tienen un propósito exclusivamente formativo y pedagógico. No sustituyen el juicio clínico profesional, no valoran casos reales, no prescriben tratamientos específicos y no constituyen en ningún caso un diagnóstico médico o de enfermería. El profesional sanitario a cargo es el único responsable de validar la idoneidad del protocolo antes de su aplicación real.
